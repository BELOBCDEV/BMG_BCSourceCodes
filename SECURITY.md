# Security Policy

## Reporting a vulnerability

Do not open a public issue for security problems. Report them privately to
the maintainers (use GitHub's "Report a vulnerability" under the Security
tab, or contact the repo owners directly).

## What we expect

- No secrets, API keys, tokens, or credentials committed to the repository.
  Secret scanning with push protection is enabled to catch these.
- Dependencies are kept patched via Dependabot.
- All changes go through pull request review before reaching the default
  branch.

## Supported

The default branch is the only supported branch. Security fixes are applied
there first.
